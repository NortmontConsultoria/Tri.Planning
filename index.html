Etapas do projeto
Rotina

Rotina de gestão da migração

A etapa 8 é a virada de chave: com os pilotos conectados, a migração deixa de ser um projeto com data de fim e passa a ser rotina de acompanhamento. O quadro de acompanhamento entra como pauta fixa da weekly e cada consultor reporta os três estágios dos clientes da sua carteira até a fase estar fechada. É essa rotina, e não o cronograma, que sustenta a meta de 31/12.

Três estágios de validação por cliente

A sequência vale para os pilotos e para cada cliente das fases seguintes.

1

Conexão

O sistema acessa a base do cliente e os dados chegam.

2

Leitura dos campos

Cada campo lido é o campo certo do ERP: produto é produto, código é código.

3

Validação dos dados

Os números e os painéis batem com a realidade do cliente.

O cliente só conta como rodando depois dos três estágios concluídos.
